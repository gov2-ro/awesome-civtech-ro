directory of civtech, open data and good governance cso projects

## Layout
- `data/projects.csv` — source catalogue, as gathered. Never edited; read for: original name, description, keywords, author, source code, contact, catalogue source.
- `data/curation.csv` — the file to edit. One row per source row (joined on `id`); a filled cell wins over the source, an empty one falls back to it.
  - `kind`: `proiect` / `organizatie` / `resursa` / `exclus` · `civictech`: 1/0
  - `name`, `tagline`, `domeniu`, `tip`, `acoperire`, `oras`, `url`, `org`, `cod`
  - `cuvinte`: comma-separated keywords; when filled it **replaces** the source keywords (both are cleaned with the rules in `taxonomy.json` → `cuvinte`)
  - `linkuri`: extra links, separated by space or `|`. Role is guessed from the domain (facebook, instagram, linkedin, x, youtube…) or given as a prefix: `donatii:https://…`, `despre:`, `contact:`, `termeni:`, `date:`, `api:`, `mcp:`. Manual links win over the social links the profiler finds on the homepage.
  - `stare` (`arhivat` / `offline` override), `imagine` (`none` hides a bad image), `nota` (internal)
- `data/international.csv` — international entries taken out of the directory (curation + source columns), kept for the future international mirror
- `data/taxonomy.json` — domenii, tipuri, acoperire, keyword cleaning rules, link roles
- `data/profile.json` — generated by the profiler: HTTP status, redirects, meta description, og:image, icon, repos, social links, Wayback link
- `site/` — static site (`index.html`, `app.js`, `style.css`, generated `data.json` and `img/`)

## Run
```sh
uv run scripts/profile.py            # profile new entries (add --force to redo all, --only slug,slug)
python3 scripts/build.py             # merge everything into site/data.json
python3 -m http.server -d site 8000  # http://localhost:8000
```
